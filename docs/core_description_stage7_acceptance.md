# Приёмка импорта описаний керна (этап 7)

## Область проверки

Чек-лист закрывает чистый парсер, семантику, БД, предпросмотр и пакетную
обработку. Автоматический корпус состоит из четырёх воспроизводимых обезличенных
DOCX; бинарные оригиналы и результаты с конфиденциальным текстом в Git не
помещаются.

## Автоматические проверки

Запуск из корня репозитория:

```bash
python tests/fixtures/core_description/generate_fixtures.py
PYTHONPATH=. pytest -q tests/test_core_description_parser.py \
  tests/test_core_description_database.py tests/test_core_description_import_ui.py \
  tests/test_core_description_batch.py
PYTHONPATH=. pytest -q
python tests/performance/core_description_benchmark.py --rounds 25 --max-seconds 10
```

Порог 10 секунд относится к 100 разборам четырёх малых фикстур на одной машине,
не является SLA для произвольных документов и выбран с запасом для CI. Скрипт
печатает JSON с общим временем, числом документов/интервалов и пропускной
способностью; превышение порога завершает процесс с кодом 1.

## Ручная проверка оригиналов

Проверку проводит уполномоченный сотрудник локально, не копируя документы в Git.
Для каждого согласованного оригинала зафиксировать только имя/внутренний
идентификатор без чувствительных данных, версию GeoVel, результат и замечания.

- [ ] файл открывается; `.doc` преобразуется без изменения оригинала;
- [ ] скважина, площадь, автор и число таблиц совпадают с оригиналом;
- [ ] количество интервалов, верх, низ и полный текст сверены построчно;
- [ ] породы, отношения, отрицания и нефтенасыщенность объясняются правилами;
- [ ] неоднозначные строки не выбираются как уверенные;
- [ ] ручная правка и выборочное сохранение прочитаны обратно из БД;
- [ ] повторный файл отклонён как точный дубль;
- [ ] повреждённый файл не остановил оставшийся пакет;
- [ ] JSON/CSV-отчёт не содержит полного текста описаний;
- [ ] отмена прекращает новые работы и не оставляет частичной транзакции.

Рекомендуемая запись результата:

| Дата | Среда/версия | Набор документов | Пройдено | Отклонения | Проверил |
|---|---|---:|---:|---|---|
| ГГГГ-ММ-ДД | ОС, Python, commit | количество | да/нет | ссылка на закрытый журнал | ФИО |

## Решение о выпуске

Выпуск разрешён, когда профильные и регрессионные тесты прошли, benchmark не
превысил согласованный порог, все поддерживаемые оригиналы проверены, а найденные
отклонения закрыты либо явно приняты владельцем данных. Отсутствие доступа к
оригиналам фиксируется как незавершённая ручная проверка, а не как успешный тест.
