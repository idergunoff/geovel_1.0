# Импорт описаний керна: инструкция пользователя и администратора

## 1. Назначение и ограничения

Импорт переносит интервалы и исходные описания керна из `.docx` и `.doc` в уже
существующую скважину GeoVel. Он **не создаёт скважины**, не выполняет OCR и не
угадывает пропущенные глубины. Исходный Word-файл в базе не хранится; для аудита
сохраняются его имя, SHA-256, исходные значения шапки и подписи, полный текст
выбранных интервалов и версии парсера и словаря.

Перед рабочим импортом сделайте резервную копию БД. Для `.doc` нужен LibreOffice
либо Microsoft Word в Windows. GeoVel сначала ищет LibreOffice в `PATH` и в
стандартных каталогах установки Windows/macOS, а при его отсутствии в Windows
автоматически использует Microsoft Word. Для переносной или нестандартной
установки LibreOffice укажите полный путь к `soffice` в переменной окружения
`LIBREOFFICE_PATH`. `.docx` читается напрямую и внешних программ не требует.
В Linux поддерживаются также пользовательская установка Flatpak и распакованная
без прав администратора версия в `~/.local/opt/libreoffice*/`.

Запуск GeoVel из Python `venv` не требует установки LibreOffice внутрь среды:
он вызывается как отдельная системная программа. Если автоматический поиск не
нашёл установку, задайте `LIBREOFFICE_PATH` в окружении запуска GeoVel, например
`C:\Program Files\LibreOffice\program\soffice.exe` в Windows. Каждый запуск
конвертации использует собственный временный профиль LibreOffice, поэтому
открытый редактор и параллельные импорты не делят профиль. Таймаут конвертации —
120 секунд; исходный DOC не изменяется, временные файлы удаляются после обработки.
В Linux при таймауте завершается группа процессов этой конвертации. Если
LibreOffice успел записать полный читаемый DOCX, GeoVel продолжает его обработку.

При запуске из PyCharm, установленного через Flatpak, GeoVel также проверяет
системный LibreOffice через `flatpak-spawn --host`. Для проверки выполните во
встроенном терминале IDE `flatpak-spawn --host /usr/bin/libreoffice --version`.
Если команда работает, переустанавливать PyCharm и задавать путь не требуется.
Временные документы и профиль создаются в кэше приложения Flatpak, доступном
системному LibreOffice, и удаляются после обработки. GeoVel не меняет разрешения
Flatpak. Если вызов запрещён, запускайте GeoVel из системного терминала.

## Просмотр загруженного описания

В **Data of Well → Well** после количества каротажных кривых появляется
голубая отметка **Есть описание керна**. В конце карточки расположен раздел
**Описание керна**: одна строка на слой в порядке глубины — геологический индекс,
глубина кровли, мощность, основная порода и нефтенасыщенность. Неизвестная
нефтенасыщенность пропускается. Слои с любыми признаками нефти, включая запах,
выделены светло-коричневым. Прочерк означает, что значение не сохранено.

Кнопка **Описание** рядом с **Керн** открывает таблицу всех сохранённых слоёв
выбранной скважины. Она доступна при наличии описания. Таблица предназначена для
просмотра и содержит индекс, кровлю, подошву, мощность, основную и второстепенные
породы, нефтенасыщенность и исходное описание. Исходный текст переносится
полностью по ширине ячейки; высота строки подстраивается при изменении ширины
столбца. Породы выделены голубым, нефтенасыщенность — жёлтым, как при загрузке.
При выборе строки внизу показаны полные исходное и нормализованное
описания, все породы, сведения об источнике и распознавании. Для широких таблиц
доступна горизонтальная прокрутка. Окно позволяет продолжать работу в GeoVel;
его заголовок показывает скважину, для которой оно открыто.

В конце строки скважины в списке стоит **▤**, если загружено описание керна.
Скважины с описанием или каротажем показываются перед остальными во всех режимах
списка: общий, по профилю и по объекту. Подсказка строки перечисляет доступные
данные. После импорта отметки и карточка обновляются автоматически.

## 2. Пошаговый импорт

1. Откройте вкладку **Layer, Well** и нажмите **Керн**. Окно импорта позволяет
   продолжать работу в основном окне. Повторное нажатие возвращает открытый импорт.
2. Нажмите **Добавить файлы…** или **Добавить каталог…**. При выборе каталога
   файлы `.doc` и `.docx` ищутся в нём и во всех вложенных папках автоматически.
3. Дождитесь окончания обработки. **Отменить обработку** прекращает запуск новых
   файлов; уже разобранные результаты остаются в предпросмотре.
4. Выберите строку документа. Проверьте имя скважины, площадь, автора и общие
   предупреждения. Ошибка одного файла не блокирует другие.
   Столбец **Скважина БД** показывает текущий автоматический или ручной выбор
   для открытого документа. Ширина всех столбцов верхней таблицы подстраивается
   под содержимое; для широкой таблицы используйте горизонтальную прокрутку.
5. Проверьте поле **Скважина БД**: список показывает номер, площадь и id;
   сначала показаны точные совпадения с названием скважины в документе, затем
   названия, содержащие его, и похожие варианты. Автоматические рекомендации
   отмечены **★**. При вводе номера в поиск список упорядочивается по введённому
   значению; выбранная скважина сохраняется, если она подходит под фильтры.
   Площадь читается из подписи или
   шапки, в том числе из третьей непустой строки. Поддерживаются названия вида
   «Сарабикуловское поднятие» → «Сарабикуловский» и «Нефтеперспективный объект №58»
   → «Объект 58» / «58». Эти варианты учитываются при сопоставлении скважин.
   Если площадь в документе не определилась, используется название папки,
   непосредственно содержащей исходный файл. В предпросмотре появляется
   предупреждение, а название отмечается **(из папки)** — проверьте его перед
   сохранением. Найденная в документе площадь всегда имеет приоритет.
   В поле **Площадь БД** можно выбрать площадь или ввести название, а в поле
   **Поиск по номеру скважины** — часть номера, как в wells. Для просмотра всех
   записей выберите **Все площади** и очистите поиск. Ручной выбор доступен и
   при отсутствии предложений. Выбор сохраняется при переключении документов
   пакета. После изменений в основном окне нажмите **Обновить список**.
   Поиск площади проверяет также значения **Data of Well** в других категориях,
   включая **Залежь** и **Месторождение**. В таблице сравнения указана категория,
   в которой найдено название.

   В списке скважин и таблице сравнения показаны **начало бурения**, **окончание
   бурения** и **альтитуда устья**. Эти сведения читаются из абзацев и таблиц
   шапки Word и сравниваются с **Data of Well**, а альтитуда — также с полем
   альтитуды скважины. Зелёным отмечены совпадения, красным — различия и
   противоречия. Для альтитуды допускается разница до **2 м включительно**,
   например при ошибочной записи отметки ротора вместо устья. Названия участков
   считаются совпавшими при сходстве **строго выше 50%** после нормализации;
   «Мельничное поднятие» и «мельничный уч» соответствуют друг другу. Процент
   нечёткого совпадения показан в таблице. Номера объектов должны совпадать точно.
   Общее название площади может совпасть с нумерованной залежью: «Верхнее поднятие»
   и «Верхнее 3». Две явно разные залежи, например «Верхнее 3» и «Верхнее 4»,
   различаются.

   Скважина выбирается автоматически при **минимум двух из пяти совпадений**:
   номер, участок, начало бурения, окончание бурения, альтитуда. Точный номер
   обязателен и считается одним из двух совпадений; достаточно ещё одного признака.
   `10 Вр`, `10вр` и `10 ВР` считаются точным совпадением номера. Его сравнение
   показано отдельной строкой таблицы. Остальные признаки могут отличаться.
   Повторы площади в разных категориях считаются одним признаком. Среди записей
   с тем же номером автоматически выбирается одна с наибольшим числом совпадений:
   например, три совпадения предпочтительнее двух. При равенстве лучших вариантов
   выбирается первая запись по id. При менее двух совпадениях выберите запись
   вручную. Если фильтр сбросил выбор,
   **Обновить список** повторяет автоматическое сопоставление. Выбранная вручную
   скважина сохраняется. Даты сравниваются независимо от формата; месяц без дня (`11.2019`)
   отмечается отдельно и в число совпавших признаков не входит. Поле с подписью
   «Альтитуда ротора» не используется как альтитуда устья.
6. Проверьте каждый выбранный интервал по оригиналу. Редактируются верх, низ,
   мощность, геологический индекс, породы, нефтенасыщенность и уверенность.
   Мощность загружается из документа; если она не указана, рассчитывается как
   разница между низом и верхом. После ручного изменения глубин проверьте мощность.
   Полный исходный текст не редактируется. В нём голубым выделены распознанные
   породы, оранжевым — признаки нефтенасыщенности, отрицания и уточнения.
   Подсказка ячейки показывает сработавшие правила словаря. Ширину столбцов можно
   менять мышью; высота строк подбирается автоматически для полного текста.
   Служебные строки с номерами столбцов (1, 2, 3, …) пропускаются при загрузке.
7. Используйте фильтры и команды выбора. Фильтр лишь скрывает строки и не меняет
   их флажки. **Вернуть автоматические значения** действует на выделенные строки.
8. Сверьте итоговый счётчик и нажмите **Сохранить выбранные**. Каждый документ
   пакетного импорта сохраняется отдельной транзакцией.
9. При необходимости экспортируйте отчёт в JSON/CSV. Отчёт содержит путь,
   статус, ошибку, длительность и число интервалов, но не полные описания.

Породы и нефтенасыщенность в таблице и фильтрах отображаются по-русски:
«Песчаник», «Аргиллит», «Известняк»; «Слабая», «Средняя», «Интенсивная»,
«От слабой до средней», «От средней до интенсивной», «От слабой до интенсивной».
«Не определена» означает отсутствие распознанной степени, «Признаки нефти
отсутствуют» — явное отрицание, «Нефтенасыщенность без указания степени» —
наличие признака без оценки интенсивности, «Нефтенасыщенность под вопросом» —
неопределённую формулировку. Дополнительные породы показывают отношение:
«прослой», «включение», «переслаивание».
Дополнительно доступны «Остаточная» (`residual`), «Запах» (`odor`) и «Пятнами»
(`patchy`): распознаются остаточная нефтенасыщенность, запах нефти/битума и
пятнистое нефтенасыщение. Упоминания пятен, запаха или остаточной влаги без
связи с нефтью/битумом не определяют нефтенасыщенность. При ручной правке используйте эти же
термины, например `Глина (прослой)`. Прежние английские коды тоже принимаются.
В БД и программном JSON остаются стабильные коды; миграция данных не требуется.
Неизвестные пользовательские названия сохраняются как введены.

## 3. Статусы и предупреждения

| Состояние | Действие пользователя |
|---|---|
| `готово` | Сверить с оригиналом; строка может быть выбрана автоматически. |
| `требует проверки` | Проверить предупреждение, сопоставление и распознанные значения вручную. |
| `ошибка` | Исправить документ либо исключить строку из сохранения. |
| `не сопоставлена` | Выбрать существующую скважину БД. |
| `дубликат` / ошибка повторного импорта | Не повторять импорт; замену выполнять только по утверждённому регламенту. |

Низкая уверенность, неопределённая формулировка, отсутствие автора и локальный
признак («местами») не должны подтверждаться автоматически. Отрицание признаков
нефти имеет приоритет перед положительным совпадением. Значения глубин должны
быть конечными и удовлетворять `верх < низ`.

## 4. Частые проблемы

- **Не найден конвертер `.doc`.** В Windows достаточно установленного Microsoft
  Word либо LibreOffice. В других системах установите LibreOffice. Для
  нестандартной установки задайте полный путь к `soffice`/`soffice.exe` в
  переменной окружения `LIBREOFFICE_PATH`, затем перезапустите GeoVel.
  Для установки без прав администратора можно использовать пользовательский
  Flatpak (`flatpak install --user flathub org.libreoffice.LibreOffice`) или
  распаковать LibreOffice в домашний каталог и указать путь через
  `LIBREOFFICE_PATH`.
  Альтернативно преобразуйте `.doc` в `.docx` на доверенной машине. Не
  переименовывайте расширение файла.
- **LibreOffice conversion timed out after 120 seconds.** Конвертер не завершился
  за две минуты и не оставил читаемый DOCX. Откройте исходный DOC в LibreOffice,
  сохраните как DOCX и загрузите сохраненный файл. Если редактор также зависает,
  приложите исходный файл и укажите версию LibreOffice для воспроизведения ошибки.
- **Не найдена таблица/шапка.** Сверьте документ с поддерживаемым шаблоном; не
  добавляйте глубины вручную без проверки исходника.
- **Несколько скважин с одним номером.** Используйте площадь и выберите запись
  вручную. Импорт никогда не должен создавать новую скважину для устранения
  неоднозначности.
- **Часть пакета завершилась ошибкой.** Сохраните корректные документы,
  экспортируйте отчёт, исправьте только ошибочные файлы и повторите их отдельно.
- **Файл уже импортирован.** Сравните SHA-256 и существующие интервалы. Обычный
  режим безопасно отклоняет точный дубль.

## 5. Администрирование словаря

В окне **Импорт описания керна** нажмите **Словари парсера…**. Откроется отдельное
окно редактирования. Во время обработки файлов кнопка недоступна.

1. Выберите раздел: породы, отношения между породами, признаки или степени
   нефтенасыщенности, отрицания, неопределённость и локальность, служебные слова.
   Поиск находит слова, шаблоны и результаты распознавания в выбранном разделе.
2. Нажмите **Добавить…** или выберите строку и нажмите **Изменить…**
   (также работает двойной щелчок). Выберите результат распознавания или введите
   собственное название. Каждое слово, словоформу или шаблон вводите с новой
   строки. Здесь же можно удалить отдельные слова, поменять раздел, тип
   совпадения, приоритет, комментарий или отключить правило целиком.
3. Для удаления правила со всеми его словами нажмите **Удалить…** и подтвердите
   удаление. Для удаления одной словоформы используйте **Изменить…**.
4. Введите пример в **Пробный разбор с текущими изменениями** и нажмите
   **Проверить текст**. Проверка использует ещё не сохранённые правки. Для слов
   и фраз учитываются границы слов; регистр не учитывается. Регулярные выражения
   подходят для сложных формулировок; проверяйте также примеры, которые не должны
   распознаваться. Служебные слова фиксируются среди совпадений и сами по себе
   не определяют породу или нефтенасыщенность.
5. Нажмите **Сохранить словари**. Пустые значения, пустые списки слов и неверные
   регулярные выражения не сохраняются. При закрытии с несохранёнными правками
   доступны сохранение, отказ от правок и возврат к редактированию.

Изменения сохраняются между запусками в пользовательском файле
`GeoVel/core_description/dictionary.json` в каталоге настроек:
`%APPDATA%` в Windows, `~/Library/Application Support` в macOS,
`$XDG_CONFIG_HOME` или `~/.config` в Linux. Точный путь показан в редакторе.
Файл устанавливаемого приложения `core_description/dictionary.json` остаётся
исходным словарём и используется, пока пользовательская копия не сохранена.
Пользовательская копия содержит полный словарь и имеет собственную версию,
которая автоматически обновляется при сохранении.

Новые загрузки, включая пакетный импорт и командную строку, используют сохранённый
словарь. **Для применения правок к уже открытым описаниям загрузите документы
повторно**; текущие ручные правки предварительно сохраните при необходимости.
Уже сохранённые в БД документы сохраняют прежние результаты и версию словаря.
Для переноса настроек можно скопировать пользовательский файл в показанный
каталог на другой машине; для возврата к исходному словарю закройте GeoVel
и переместите пользовательский файл из этого каталога.

Для разработчиков: формат правил описан в
`core_description/dictionary.schema.json`. Идентификаторы правил должны быть
уникальны; редактор создаёт их автоматически и сохраняет при изменении слов.
Изменения исходного словаря приложения проверяйте регрессионными примерами:
